## 10-1 主要簿と補助簿

### 主要簿

すべての取引を記録する、もっとも基本の帳簿を**主要簿**といいます。主要簿は次の2つです。

| 帳簿 | 内容 |
|---|---|
| **仕訳帳** | すべての取引を、起きた順に仕訳の形で記録する |
| **総勘定元帳** | 仕訳を、勘定科目ごとに転記して集める(第1章のT字勘定の正式な形) |

たとえば「7月2日 商品46,000円を掛けで仕入れた」という取引は、次のように記入します。

**仕訳帳**

| 日付 | 摘要 | 元丁 | 借方 | 貸方 |
|---|---|---|---:|---:|
| 7/2 | (仕入) | 31 | 46,000 | |
| | 　　(買掛金) | 12 | | 46,000 |
| | えがお物産から掛けで仕入れ | | | |

**総勘定元帳** 仕入(31)

| 日付 | 摘要 | 仕丁 | 借方 | 日付 | 摘要 | 仕丁 | 貸方 |
|---|---|---|---:|---|---|---|---:|
| 7/2 | 買掛金 | 1 | 46,000 | | | | |

- 仕訳帳の**摘要**には、借方の科目を上、貸方の科目を1行下に少しずらして書き、その下に取引の説明(**小書き**)を書きます
- **元丁**(もとちょう)は、転記した先の総勘定元帳のページ番号です。転記がすんだしるしにもなります
- 総勘定元帳の**摘要**には、仕訳の相手の科目を書きます。**仕丁**(しちょう)は、転記元の仕訳帳のページ番号です

### 補助簿

主要簿だけでは足りない、**くわしい情報**を記録する帳簿を**補助簿**といいます。
補助簿は、次の2種類に分かれます。

| 種類 | 帳簿 | 記録すること |
|---|---|---|
| **補助記入帳** | 現金出納帳 | 現金の入金・出金の明細 |
| (取引の明細を記録) | 当座預金出納帳 | 当座預金の預け入れ・引き出しの明細 |
| | 小口現金出納帳 | 小口現金の支払いの明細(小口現金のしくみは第3章) |
| | 仕入帳 | 仕入の明細(仕入先、品名、数量、単価) |
| | 売上帳 | 売上の明細(得意先、品名、数量、単価) |
| **補助元帳** | 商品有高帳 | 商品の種類ごとの受け入れ・払い出し・残高(数量と原価) |
| (勘定科目の内訳を記録) | 売掛金元帳(得意先元帳) | 得意先ごとの売掛金の増減と残高 |
| | 買掛金元帳(仕入先元帳) | 仕入先ごとの買掛金の増減と残高 |
| | 固定資産台帳 | 固定資産ごとの取得日・取得原価・減価償却累計額など |

## 10-2 補助簿の選択

試験では、「この取引は、どの補助簿に記入されるか」がよく問われます。
次の順で考えると、もれなく選べます。

1. まず**仕訳を書く**
2. 仕訳に出てきた勘定科目ごとに、対応する補助簿を選ぶ

| 仕訳に出てくる勘定科目 | 記入する補助簿 |
|---|---|
| 現金 | 現金出納帳 |
| 当座預金 | 当座預金出納帳 |
| 小口現金 | 小口現金出納帳 |
| 仕入 | **仕入帳** と **商品有高帳** |
| 売上 | **売上帳** と **商品有高帳** |
| 売掛金 | 売掛金元帳 |
| 買掛金 | 買掛金元帳 |
| 建物・備品など | 固定資産台帳 |

普通預金・未払金・発送費・クレジット売掛金・電子記録債権などには、3級で対応する補助簿はありません。
とくに、**クレジット売掛金や電子記録債権を売掛金元帳に記入しない**ように気をつけましょう。売掛金元帳は、売掛金勘定の内訳を記録する帳簿です。

> **注意**:商品有高帳は、商品の**数量や原価**が動いたときに記入します。仕入・売上だけでなく、返品(仕入戻し・売上戻り)でも記入します。
> 引取運賃などの仕入諸掛りは、受け入れた商品の単価(原価)に含めて記入します。
> 一方、商品が動かない**発送費**(売上諸掛り)は、商品有高帳に記入しません。
> 売上原価対立法で記帳している場合は、**商品**勘定や**売上原価**勘定が動いたときに商品有高帳に記入します。

### 例題1

商品100,000円を仕入れ、代金のうち30,000円は現金で支払い、残額は掛けとした。また、引取運賃2,000円を現金で支払った。

**考え方**

仕訳は次のとおりです。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|---:|---|---:|
| 仕入 | 102,000 | 現金 | 32,000 |
| | | 買掛金 | 70,000 |

- 仕入 → **仕入帳**、**商品有高帳**
- 現金 → **現金出納帳**
- 買掛金 → **買掛金元帳**

## 10-2-2 主な補助簿の記入例

補助簿の形は、試験でも示されることがあります。主な補助簿の記入例を見ておきましょう。
商品有高帳は、次の10-3でくわしく学びます。

### 現金出納帳

現金の**収入・支出・残高**を、日付順に記録します。

**現金出納帳**(5月)

| 日付 | 摘要 | 収入 | 支出 | 残高 |
|---|---|---:|---:|---:|
| 5/1 | 前月繰越 | 50,000 | | 50,000 |
| 5/5 | えがお物産から仕入れた商品の引取運賃 | | 2,000 | 48,000 |
| 5/12 | 取引の仲介手数料を受け取り | 8,000 | | 56,000 |
| 5/20 | 郵便切手を購入 | | 3,000 | 53,000 |
| 5/31 | 次月繰越 | | 53,000 | |
| | 合計 | **58,000** | **58,000** | |

月末に、残高を「次月繰越」として支出欄に書き、収入と支出の合計を一致させて締め切ります。
当座預金出納帳もほぼ同じ形です(「預入」「引出」欄のほか、残高が借方か貸方かを書く「借/貸」欄があり、当座借越の状態のときは「貸」と書きます)。

**当座預金出納帳**(7月、当座借越契約あり)

| 日付 | 摘要 | 預入 | 引出 | 借/貸 | 残高 |
|---|---|---:|---:|---|---:|
| 7/1 | 前月繰越 | 40,000 | | 借 | 40,000 |
| 7/9 | 買掛金を当座預金口座から振り込んで支払い | | 65,000 | 貸 | 25,000 |
| 7/22 | 売掛金が当座預金に振り込まれた | 90,000 | | 借 | 65,000 |
| 7/31 | 次月繰越 | | 65,000 | | |
| | 合計 | **130,000** | **130,000** | | |

- 7月9日は、残高40,000円を超えて65,000円を引き出したので、残高は**貸方25,000円**(当座借越の状態)です
- 7月22日の預け入れで、残高は借方65,000円に戻ります

### 小口現金出納帳

小口係が、小口現金の**受入・支払**と、支払いの**内訳**を記録します(小口現金のしくみは第3章)。
次の例は、定額30,000円の定額資金前渡法で、週末に使った分を補給する場合です。

**小口現金出納帳**

| 受入 | 日付 | 摘要 | 支払 | 旅費交通費 | 通信費 | 消耗品費 | 残高 |
|---:|---|---|---:|---:|---:|---:|---:|
| 30,000 | 6/1 | 前週繰越 | | | | | 30,000 |
| | 6/2 | バス代 | 3,000 | 3,000 | | | 27,000 |
| | 6/3 | 郵便切手 | 2,500 | | 2,500 | | 24,500 |
| | 6/4 | コピー用紙 | 4,000 | | | 4,000 | 20,500 |
| | 6/5 | タクシー代 | 5,000 | 5,000 | | | 15,500 |
| | | 合計 | 14,500 | 8,000 | 2,500 | 4,000 | |
| 14,500 | 6/5 | 本日補給 | | | | | 30,000 |
| | 〃 | 次週繰越 | 30,000 | | | | |
| **44,500** | | | **44,500** | | | | |
| 30,000 | 6/8 | 前週繰越 | | | | | 30,000 |

- 内訳欄の合計(旅費交通費8,000円・通信費2,500円・消耗品費4,000円)が、会計係が仕訳する金額です(第3章 例題8と同じ考え方)
- 補給後は、残高が定額の30,000円に戻ります
- 受入欄と支払欄の合計(44,500円)を一致させて締め切ります

### 仕入帳(売上帳)

仕入の**明細**(仕入先・品名・数量・単価・支払方法)を記録します。売上帳も同じ形です。

**仕入帳**(5月)

| 日付 | 摘要 | 内訳 | 金額 |
|---|---|---:|---:|
| 5/5 | えがお物産株式会社 掛け | | |
| | ボールペン 500本 @60円 | 30,000 | |
| | ノート 200冊 @150円 | 30,000 | |
| | 引取運賃 現金払い | 2,000 | 62,000 |
| 5/7 | えがお物産株式会社 掛け返品 | | |
| | ノート 20冊 @150円 | | 3,000 |
| 5/31 | 総仕入高 | | 62,000 |
| 〃 | 仕入戻し高 | | 3,000 |
| 〃 | **純仕入高** | | **59,000** |

- 引取運賃などの付随費用も、仕入帳の金額に含めます(第2章)
- 返品(仕入戻し)は、ふつう**赤字**で書き、月末に総仕入高から差し引きます(この表では赤字の代わりに行を分けています)

### 売掛金元帳(得意先元帳)

得意先**ごと**に、売掛金の増減と残高を記録します。買掛金元帳(仕入先元帳)も同じ形で、仕入先ごとに買掛金を記録します。
ただし、買掛金は負債なので、借方と貸方が**逆**になります(前月繰越は**貸方**、残高はふつう**貸方**、月末の次月繰越は**借方**に書きます)。

**売掛金元帳** あおば商店株式会社(5月)

| 日付 | 摘要 | 借方 | 貸方 | 借/貸 | 残高 |
|---|---|---:|---:|---|---:|
| 5/1 | 前月繰越 | 80,000 | | 借 | 80,000 |
| 5/8 | 売上 | 150,000 | | 借 | 230,000 |
| 5/10 | 返品 | | 10,000 | 借 | 220,000 |
| 5/25 | 普通預金で回収 | | 120,000 | 借 | 100,000 |
| 5/31 | 次月繰越 | | 100,000 | | |
| | 合計 | **230,000** | **230,000** | | |

- 売掛金は資産なので、ふつう**借方残高**です。「借/貸」欄には、残高が借方か貸方かを書きます
- 月末に、残高を「次月繰越」として貸方に書き、借方と貸方の合計を一致させて締め切ります
- 総勘定元帳の売掛金勘定には全得意先の合計が、売掛金元帳には得意先ごとの内訳が記録されます

### 固定資産台帳

固定資産**ごと**に、取得日・取得原価・減価償却累計額などを記録します。
試験では、**固定資産台帳を読み取って、当期の減価償却費を計算する**問題がよく出ます。

**固定資産台帳**(会計期間:×3年4月1日〜×4年3月31日、定額法、残存価額0円)

| 取得年月日 | 名称 | 耐用年数 | 取得原価 | 期首減価償却累計額 | 期首(期中取得)帳簿価額 | 当期減価償却費 |
|---|---|---:|---:|---:|---:|---:|
| ×1年4月1日 | 備品A | 6年 | 600,000 | 200,000 | 400,000 | (ア) |
| ×2年10月1日 | 備品B | 5年 | 480,000 | 48,000 | 432,000 | (イ) |
| ×3年12月1日 | 備品C | 4年 | 360,000 | 0 | 360,000 | (ウ) |

「期首(期中取得)帳簿価額」は、期首からある資産は期首の帳簿価額、当期の途中で取得した資産(備品C)は取得したときの金額を書く欄です。

**考え方**

- (ア)備品A:600,000円 ÷ 6年 = **100,000円**(期首累計200,000円は2年分で、計算と合っている)
- (イ)備品B:480,000円 ÷ 5年 = 96,000円。期首累計48,000円は前期の6か月分(10月〜3月)。当期は1年分なので **96,000円**
- (ウ)備品C:当期の12月に取得したので4か月分(12月〜3月)。360,000円 ÷ 4年 × 4 ÷ 12 = **30,000円**
- 当期の減価償却費の合計:100,000円 + 96,000円 + 30,000円 = 226,000円

決算整理仕訳は次のとおりです。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|---:|---|---:|
| 減価償却費 | 226,000 | 備品減価償却累計額 | 226,000 |

期末の備品減価償却累計額は、期首の合計248,000円 + 226,000円 = **474,000円**になります。

> **ポイント**:期首減価償却累計額は「何年(何か月)分か」を確かめる手がかりになります。
> 前期の途中で取得した資産(備品B)は、**前期は月割、当期は1年分**です。

## 10-3 商品有高帳

### しくみ

**商品有高帳**(しょうひんありだかちょう)は、商品の種類ごとに、**受け入れ**(仕入)・**払い出し**(売上)・**残高**を、**数量・単価・金額**で記録する帳簿です。

商品有高帳の金額は、すべて**原価**で記録します。売上のときも、売価ではなく**払い出した商品の原価**を書きます。

### 払出単価の決め方

同じ商品でも、仕入れた時期によって単価が違うことがあります。
そこで、払い出すときの単価の決め方が2つあります。

| 方法 | 考え方 |
|---|---|
| **先入先出法** | **先に仕入れたものから先に**払い出したとみなす |
| **移動平均法** | 仕入れるたびに、残っている商品と合わせた**平均単価**を計算し直し、その単価で払い出す |

### 例題2 先入先出法

商品Xの4月の受け払いは次のとおりである。先入先出法で商品有高帳に記入しなさい。

| 日付 | 内容 |
|---|---|
| 4月1日 | 前月繰越 10個 @100円 |
| 4月5日 | 仕入 20個 @115円 |
| 4月10日 | 売上 25個 @200円(売価) |
| 4月20日 | 仕入 15個 @130円 |
| 4月25日 | 売上 12個 @200円(売価) |

**商品有高帳(先入先出法)** 商品X

| 日付 | 摘要 | 受入数量 | 受入単価 | 受入金額 | 払出数量 | 払出単価 | 払出金額 | 残高数量 | 残高単価 | 残高金額 |
|---|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| 4/1 | 前月繰越 | 10 | 100 | 1,000 | | | | 10 | 100 | 1,000 |
| 4/5 | 仕入 | 20 | 115 | 2,300 | | | | 10 | 100 | 1,000 |
| | | | | | | | | 20 | 115 | 2,300 |
| 4/10 | 売上 | | | | 10 | 100 | 1,000 | | | |
| | | | | | 15 | 115 | 1,725 | 5 | 115 | 575 |
| 4/20 | 仕入 | 15 | 130 | 1,950 | | | | 5 | 115 | 575 |
| | | | | | | | | 15 | 130 | 1,950 |
| 4/25 | 売上 | | | | 5 | 115 | 575 | | | |
| | | | | | 7 | 130 | 910 | 8 | 130 | 1,040 |

**ポイント**

- 単価の違う商品は、残高欄に**行を分けて**書く
- 4月10日の25個は、古い順に「@100円を10個」「@115円を15個」払い出す
- 4月中の払出金額(売上原価)の合計は、1,000円 + 1,725円 + 575円 + 910円 = **4,210円**

### 例題3 移動平均法

例題2と同じ資料を、移動平均法で記入しなさい。

**商品有高帳(移動平均法)** 商品X

| 日付 | 摘要 | 受入数量 | 受入単価 | 受入金額 | 払出数量 | 払出単価 | 払出金額 | 残高数量 | 残高単価 | 残高金額 |
|---|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| 4/1 | 前月繰越 | 10 | 100 | 1,000 | | | | 10 | 100 | 1,000 |
| 4/5 | 仕入 | 20 | 115 | 2,300 | | | | 30 | 110 | 3,300 |
| 4/10 | 売上 | | | | 25 | 110 | 2,750 | 5 | 110 | 550 |
| 4/20 | 仕入 | 15 | 130 | 1,950 | | | | 20 | 125 | 2,500 |
| 4/25 | 売上 | | | | 12 | 125 | 1,500 | 8 | 125 | 1,000 |

**平均単価の計算**

- 4月5日:(1,000円 + 2,300円) ÷ (10個 + 20個) = 3,300円 ÷ 30個 = **@110円**
- 4月20日:(550円 + 1,950円) ÷ (5個 + 15個) = 2,500円 ÷ 20個 = **@125円**

4月中の払出金額(売上原価)の合計は、2,750円 + 1,500円 = **4,250円**です。

### 商品有高帳の締切りと返品の記入

- **締切り**:月末に、残高を「**次月繰越**」として**払出欄**に記入し、受入欄と払出欄の合計を一致させます。翌月の最初に「前月繰越」として受入欄に記入します。
  例題2なら、受入欄の合計(1,000円 + 2,300円 + 1,950円 = 5,250円)と、払出欄の合計(払出4,210円 + 次月繰越1,040円 = 5,250円)が一致します。
- **仕入戻し**:返品した商品は、**払出欄**に、仕入れたときの単価で記入します。
- **売上戻り**:戻ってきた商品は、**受入欄**に、払い出したときの単価(原価)で記入します。売価ではありません。

### 売上総利益の計算

試験では、商品有高帳を作ったうえで、**売上高・売上原価・売上総利益**を問われることがよくあります。

| | 先入先出法 | 移動平均法 |
|---|---:|---:|
| 売上高(売価) | 37個 × @200円 = 7,400円 | 7,400円 |
| 売上原価(払出金額の合計) | 4,210円 | 4,250円 |
| **売上総利益** | **3,190円** | **3,150円** |

> **確認のしかた**:売上原価 = 月初の残高 + 当月の受入 − 月末の残高 になっているか確かめましょう。
> 先入先出法なら 1,000円 + 当月の受入(2,300円 + 1,950円) − 1,040円 = 4,210円 で一致します。

## 10-4 証ひょうからの仕訳

**証ひょう**(しょうひょう)とは、取引があったことを証明する書類です。
**納品書**、**請求書**、**領収書**、**振込依頼書**、**旅費交通費等報告書**、**通帳の記録**などがあります。

第1問では、証ひょうを読み取って仕訳をする問題が出題されます。
次の点に注目して読んでください。

- **誰が誰に**出した書類か(当社が受け取ったのか、発行したのか)
- **品物は何か**(商品か、備品か、消耗品か)
- **送料**が含まれているか、**消費税**はいくらか
- **支払方法**(掛け、振込、現金など)

### 例題4

ひかり商事株式会社は、商品を仕入れ、品物とともに次の請求書を受け取った。代金は月末に支払う予定である。消費税は税抜方式で処理し、商品売買は三分法による。

```
                       請 求 書
ひかり商事株式会社 御中                   えがお物産株式会社

  品  名          数 量     単 価         金 額
  ボールペン       500     60         30,000
  ノート          200    150         30,000
  送料                                1,000
                              小  計   61,000
                              消費税    6,100
                              合  計   67,100

  支払期限:当月末日
```

**考え方**

- 当社が**受け取った**請求書で、品物は**商品** → 仕入
- 送料は仕入先から請求されている、仕入にかかる費用 → **仕入に含める**(第2章)
- 消費税は仮払消費税(第8章)
- 後払いなので買掛金

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|---:|---|---:|
| 仕入 | 61,000 | 買掛金 | 67,100 |
| 仮払消費税 | 6,100 | | |

出張から戻った従業員が、使った交通費や宿泊費をまとめて会社に出す書類です。出張前に概算額を渡していれば、**仮払金の精算**(第5章)になります。

**例**:従業員が出張から戻り、次の報告書を提出した。出張前に概算額25,000円を現金で渡し、仮払金で処理している。残額は現金で返金を受けた。

  さくら市        電  車      無        3,600
  ホテルさくら    宿  泊      有       14,000
  さくら市内      タクシー    有        2,500
  帰  社          電  車      無        3,600
                              合  計   23,700

## 10-5 3伝票制

### 伝票とは

取引を仕訳帳に書くかわりに、**伝票**という紙(またはデータ)に記録する方法があります。
伝票なら、担当者が取引ごとに分担して書けるので便利です。

3級では、次の3種類の伝票を使う**3伝票制**を学びます。

| 伝票 | 使う取引 | 仕訳の形 | 伝票に書く科目 |
|---|---|---|---|
| **入金伝票** | 現金が**増えた**取引 | (現金)/(○○) | 相手の科目(○○)だけ |
| **出金伝票** | 現金が**減った**取引 | (○○)/(現金) | 相手の科目(○○)だけ |
| **振替伝票** | 現金が**動かない**取引 | (○○)/(△△) | 借方・貸方の両方 |

入金伝票は借方が必ず現金、出金伝票は貸方が必ず現金なので、**相手の科目だけ**を書けば済みます。

### 例題5

次の取引を、それぞれ伝票に記入しなさい。

1. 売掛金50,000円を現金で回収した。
   → **入金伝票**(売掛金 50,000)
2. 郵便切手4,000円を現金で購入した。
   → **出金伝票**(通信費 4,000)
3. 商品80,000円を掛けで売り上げた。
   → **振替伝票**(借方 売掛金 80,000 / 貸方 売上 80,000)

### 一部現金取引

1つの取引の中に、**現金の部分と現金でない部分**が混ざっていることがあります。これを**一部現金取引**といいます。
伝票への書き方は2通りあります。

**例**:商品100,000円を仕入れ、代金のうち30,000円は現金で支払い、残額は掛けとした。

**方法① 取引を分解する**

現金で仕入れた部分と、掛けで仕入れた部分に分けて考えます。

- 出金伝票:仕入 30,000
- 振替伝票:

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|---:|---|---:|
| 仕入 | 70,000 | 買掛金 | 70,000 |

**方法② いったん全額を掛けとする**

全額をいったん掛けで仕入れ、すぐにその一部を現金で払った、と考えます。

- 振替伝票:

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|---:|---|---:|
| 仕入 | 100,000 | 買掛金 | 100,000 |

- 出金伝票:買掛金 30,000

どちらの方法でも、取引が終わったあとの**各勘定の残高は同じ**になります(仕入が100,000円増え、買掛金が70,000円増え、現金が30,000円減る)。
ただし、方法②では買掛金を借方30,000円・貸方100,000円と両方に書くので、**仕訳の形や、買掛金の借方・貸方それぞれの合計額は違います**。
試験では、片方の伝票が与えられ、もう片方の伝票を答える問題がよく出ます。
**与えられた伝票の科目**(出金伝票が「仕入」か「買掛金」か)を見て、どちらの方法かを判断してください。

## 10-6 仕訳日計表

伝票が多くなると、1枚ずつ総勘定元帳に転記するのは大変です。
そこで、1日分の伝票を**勘定科目ごとに集計**した表を作り、その合計を総勘定元帳に転記します。この表を**仕訳日計表**といいます。

### 例題6

ある日の伝票は、次の6枚だった。仕訳日計表を作成しなさい。

- 入金伝票:売掛金 50,000
- 入金伝票:売上 20,000
- 出金伝票:買掛金 30,000
- 出金伝票:通信費 4,000
- 振替伝票:(借方)売掛金 80,000 /(貸方)売上 80,000
- 振替伝票:(借方)仕入 60,000 /(貸方)買掛金 60,000

**考え方**

- 現金の借方 = 入金伝票の合計:50,000円 + 20,000円 = 70,000円
- 現金の貸方 = 出金伝票の合計:30,000円 + 4,000円 = 34,000円
- それ以外の科目は、入金伝票の科目は貸方、出金伝票の科目は借方、振替伝票はそのまま集計する

**仕訳日計表**

| 借方 | 勘定科目 | 貸方 |
|---:|---|---:|
| 70,000 | 現金 | 34,000 |
| 80,000 | 売掛金 | 50,000 |
| 30,000 | 買掛金 | 60,000 |
| | 売上 | 100,000 |
| 60,000 | 仕入 | |
| 4,000 | 通信費 | |
| **244,000** | 合計 | **244,000** |

借方合計と貸方合計は、必ず一致します。

**転記のしかた**

- **総勘定元帳**へは、仕訳日計表の勘定科目ごとの**合計額**を転記します(摘要欄には「仕訳日計表」と書きます)
- **売掛金元帳・買掛金元帳**へは、取引先ごとの内訳が必要なので、**個々の伝票から**転記します

## まとめ

- 主要簿は**仕訳帳**と**総勘定元帳**。補助簿は**補助記入帳**(取引の明細)と**補助元帳**(科目の内訳)
- 補助簿の選択は、**まず仕訳を書き**、科目ごとに帳簿を選ぶ。仕入・売上は**商品有高帳**にも記入する
- 売掛金元帳・買掛金元帳は**取引先ごと**の内訳。固定資産台帳から当期の減価償却費を計算できる(前期の途中で取得した資産は、当期は1年分)
- 商品有高帳は**原価**で記入する。**先入先出法**は古いものから払い出し、**移動平均法**は仕入のたびに平均単価を計算し直す
- 証ひょうは「誰が出したか」「何を買ったか」「送料・消費税」「支払方法」を読み取る
- 3伝票制:現金が増えたら**入金伝票**、減ったら**出金伝票**、それ以外は**振替伝票**。一部現金取引は2通りの書き方がある
- 仕訳日計表で、1日分の伝票を勘定科目ごとに集計する
