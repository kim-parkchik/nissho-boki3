## 13-1 決算の流れ

| 手順 | 内容 |
|---|---|
| ① 決算整理前残高試算表 | 期中の記録を集計する(第11章) |
| ② 決算整理仕訳 | 期末の正しい状態に直す(第12章) |
| ③ 精算表 | ①と②を1枚の表にまとめ、利益を計算する(この章) |
| ④ 決算整理後残高試算表 | ①に②を反映した後の残高を一覧にする(この章) |
| ⑤ 財務諸表 | 損益計算書・貸借対照表を作る(この章) |
| ⑥ 帳簿の締切り | 次の期に備えて、総勘定元帳を締め切る(この章) |

第12章の「③ 表の作成と締切り」を、この章では③〜⑥に分けて学びます。③と④は、どちらか一方だけを作ることもあります。

試験の第3問では、③の精算表、④の決算整理後残高試算表、⑤の財務諸表のどれかを作る問題がよく出ます。どれも、②の決算整理仕訳が正しく書けるかどうかで決まります。

## 13-2 精算表

### 精算表の形

**精算表**は、試算表から財務諸表ができるまでを1枚にまとめた表です。
3級では、次の**8桁精算表**(金額欄が8列)を使います。

| 欄 | 書くこと |
|---|---|
| 試算表 | 決算整理前残高試算表の金額 |
| 修正記入 | 決算整理仕訳の金額 |
| 損益計算書 | 収益・費用の、修正後の金額 |
| 貸借対照表 | 資産・負債・純資産の、修正後の金額 |

### 作り方

1. **修正記入欄**に、決算整理仕訳を記入する(借方の金額は借方、貸方の金額は貸方)
2. 試算表欄に**ない勘定科目**(貸倒引当金繰入、減価償却費、前払保険料など)は、下の空いている行に書き加える
3. 各行で、試算表欄の金額に修正記入欄の金額を**足し引き**し、
   収益・費用なら**損益計算書欄**へ、資産・負債・純資産なら**貸借対照表欄**へ書く
4. 損益計算書欄の**貸方合計 − 借方合計**が当期純利益。損益計算書欄の借方と、貸借対照表欄の貸方に記入する
5. 4つの欄すべてで、借方合計と貸方合計が一致することを確かめる

> **足し引きのルール**:試算表欄と修正記入欄が**同じ側**なら足し、**反対側**なら引きます。
> 例:保険料 試算表 借方36,000円、修正記入 貸方24,000円 → 損益計算書 借方12,000円

## 13-2-2 決算整理後残高試算表

**決算整理後残高試算表**は、決算整理仕訳を反映した**後**の、各勘定の残高を一覧にした表です。
第11章で作った試算表と同じ形で、金額が決算整理後のものになります。

作り方は、精算表の考え方と同じです。各勘定について、**試算表の金額 ± 決算整理仕訳の金額**を計算し、残高を書きます。
精算表の「損益計算書欄」と「貸借対照表欄」を、当期純利益の行を除いて1つの表にまとめたものと考えることもできます。

## 13-3 損益計算書

### 勘定科目と表示科目

財務諸表では、勘定科目の名前をそのまま使わず、**表示用の名前**に変えるものがあります。

| 勘定科目 | 損益計算書での表示 |
|---|---|
| 売上 | **売上高** |
| 仕入(売上原価を計算したあと) | **売上原価** |

「法人税、住民税及び事業税」は、勘定科目と表示科目が同じ名前です(第8章)。

## 13-4 貸借対照表

### 表示のルール

| 勘定科目 | 貸借対照表での表示 |
|---|---|
| 繰越商品 | **商品** |
| 前払保険料・前払家賃など | **前払費用** |
| 未収手数料・未収利息など | **未収収益** |
| 未払利息・未払家賃など | **未払費用** |
| 前受地代・前受家賃など | **前受収益** |
| 当座借越 | **借入金**(第3章。答案用紙や問題文に指示があれば、それに従う) |

**資産から差し引く勘定(評価勘定といいます)の表示**:貸倒引当金と減価償却累計額は、対応する資産の下に書き、**差し引く形**で表示します。

**繰越利益剰余金**:決算整理前の残高に、**当期純利益を加えた金額**を表示します。当期純損失のときは、その分を**差し引いた金額**です。

### 例題3

例題1の資料から、貸借対照表を作成しなさい。

**貸借対照表**

ひかり商事株式会社 ×2年3月31日

| 資産 | 金額 | 負債及び純資産 | 金額 |
|---|---:|---|---:|
| 現金 | 150,000 | 買掛金 | 380,000 |
| 普通預金 | 1,336,000 | 借入金 | 400,000 |
| 売掛金 470,000 | | 未払費用 | 4,000 |
| 　貸倒引当金 △9,400 | 460,600 | 未払法人税等 | 51,880 |
| 商品 | 150,000 | 資本金 | 1,000,000 |
| 貯蔵品 | 3,000 | 繰越利益剰余金 | 537,720 |
| 前払費用 | 24,000 | | |
| 未収収益 | 10,000 | | |
| 備品 600,000 | | | |
| 　減価償却累計額 △360,000 | 240,000 | | |
| **合計** | **2,373,600** | **合計** | **2,373,600** |

**計算のポイント**

- 売掛金:470,000円 − 9,400円 = 460,600円
- 備品:600,000円 − 360,000円 = 240,000円
- 繰越利益剰余金:300,000円 + 当期純利益237,720円 = 537,720円

貸借対照表は**ある時点**(期末)の状態なので、日付は決算日だけを書きます。

> **精算表との違い**:精算表の貸借対照表欄の合計(2,743,000円)と、貸借対照表の合計(2,373,600円)は一致しません。
> 貸借対照表では、貸倒引当金(9,400円)と減価償却累計額(360,000円)を資産から**差し引いて**いるからです。
> 2,743,000円 − 9,400円 − 360,000円 = 2,373,600円 です。

## 13-5 帳簿の締切り

財務諸表を作ったら、次の期に備えて総勘定元帳を**締め切ります**。

### ① 収益・費用の勘定を損益勘定に振り替える

決算で**損益**という勘定を新しく作り、収益と費用の残高をすべて集めます。
収益・費用の勘定は、残高が0になって締め切られます。これを**決算振替仕訳**といいます。

**収益の振替**(例題1の金額)

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|---:|---|---:|
| 売上 | 3,600,000 | 損益 | 3,660,000 |
| 受取手数料 | 60,000 | | |

**費用の振替**

| 借方科目 | 金額 | 貸方科目 | 金額 |

### ③ 資産・負債・純資産の勘定を締め切る

資産・負債・純資産の勘定は、残高を翌期に引き継ぎます。
残高の反対側に「**次期繰越**」と書いて貸借を一致させて締め切り、翌期首に、次期繰越の反対側(もとの残高と同じ側)へ「**前期繰越**」と書きます。
この記入は仕訳をせずに、勘定に直接書き込みます。
このように、資産・負債・純資産の勘定を、仕訳をせずに勘定の上で直接「次期繰越」と書いて締め切る方法を**英米式決算法**といいます。3級ではこの方法を使います。

```
                       現   金
──────────────────────┬──────────────────────
 (期中の借方合計)     │ (期中の貸方合計)
                      │ 3/31 次期繰越  150,000
──────────────────────┼──────────────────────
 4/1  前期繰越 150,000 │
```

## 13-6 経過勘定の勘定記入

試験の第2問では、受取地代と前受地代のような**収益(費用)の勘定と経過勘定**を組にして、1年分の記入を答えさせる問題がよく出ます。
使う知識は、次の3つです。

- 期首の**再振替仕訳**(第9章)
- 決算での**前受・前払・未収・未払**の処理(第9章)
- 決算での**損益への振替**と**次期繰越**(この章の13-5)

勘定の「摘要」には、仕訳の**相手の勘定科目**を書きます(第1章 1-7)。たとえば (前受地代)/(受取地代) の仕訳なら、受取地代勘定の貸方の摘要は「前受地代」、前受地代勘定の借方の摘要は「受取地代」です。

### 例題4

ふたば商事株式会社(会計期間は×3年4月1日〜×4年3月31日)は、土地の一部を貸していて、**毎年11月1日に向こう1年分の地代**を普通預金口座で受け取っています。
前期の×2年11月1日に受け取った地代は72,000円、当期の×3年11月1日に受け取った地代は、値上げにより84,000円でした。
前受分は決算で前受地代勘定に振り替え、翌期首に再振替仕訳をしています。
当期の受取地代勘定と前受地代勘定に記入し、締め切りなさい。

**考え方**:日付の順に、勘定に記入される仕訳を書き出します。

**×3年4月1日 再振替仕訳**

前期末(×3年3月31日)の前受分は、×2年11月に受け取った72,000円のうち、×3年4月〜10月の7か月分です。
72,000円 × 7 ÷ 12 = 42,000円。この金額が、前受地代勘定の貸方に「前期繰越 42,000」として前期から繰り越されています(13-5の③)。期首に、これを受取地代へ振り戻します。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|---:|---|---:|
| 前受地代 | 42,000 | 受取地代 | 42,000 |

**×3年11月1日 1年分の受け取り**

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|---:|---|---:|
| 普通預金 | 84,000 | 受取地代 | 84,000 |

**×4年3月31日 決算整理(前受分の振替)**

×3年11月に受け取った84,000円のうち、×4年4月〜10月の7か月分は翌期の分です。
84,000円 × 7 ÷ 12 = 49,000円

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|---:|---|---:|
| 受取地代 | 49,000 | 前受地代 | 49,000 |

**×4年3月31日 決算振替(損益への振替)**

受取地代勘定の残高は、42,000円 + 84,000円 − 49,000円 = 77,000円 です。これを損益勘定へ振り替えます。

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|---:|---|---:|
| 受取地代 | 77,000 | 損益 | 77,000 |

77,000円は、当期12か月分の地代です。4月〜10月の7か月分は前期に受け取った分(1か月6,000円 × 7 = 42,000円)、11月〜3月の5か月分は当期に受け取った分(1か月7,000円 × 5 = 35,000円)です。
地代が値上げされた年は、受け取った1年分の金額(84,000円)とは一致しないことに気をつけましょう。

**解答**

**受取地代**

| 日付 | 摘要 | 金額 | 日付 | 摘要 | 金額 |
|---|---|---:|---|---|---:|
| ×4/3/31 | 前受地代 | 49,000 | ×3/4/1 | 前受地代 | 42,000 |
| ×4/3/31 | 損益 | 77,000 | ×3/11/1 | 普通預金 | 84,000 |
| | | 126,000 | | | 126,000 |

**前受地代**

| 日付 | 摘要 | 金額 | 日付 | 摘要 | 金額 |
|---|---|---:|---|---|---:|
| ×3/4/1 | 受取地代 | 42,000 | ×3/4/1 | 前期繰越 | 42,000 |
| ×4/3/31 | 次期繰越 | 49,000 | ×4/3/31 | 受取地代 | 49,000 |
| | | 91,000 | | | 91,000 |

- 受取地代は**収益**なので、残高を「**損益**」へ振り替えて締め切ります
- 前受地代は**負債**なので、残高(貸方)の反対側の**借方**に「**次期繰越**」と書いて締め切ります。翌期首(×4年4月1日)には、貸方に「前期繰越 49,000」と書き、同じ日に再振替仕訳で借方に「受取地代 49,000」と書きます
- 同じ日付(3月31日)の行は、決算整理 → 決算振替の順に書くのがふつうです

> **費用の前払いの場合**:保険料と前払保険料のような組では、左右が逆になります。保険料勘定は**借方**に期首の再振替(前払保険料)と支払った金額が入り、**貸方**に決算の前払保険料と「損益」が入ります。前払保険料は資産で残高は借方にあるので、反対側の**貸方**に「次期繰越」と書いて締め切ります。

未払い・未収の組も含めて、4つのパターンで記入する側をまとめると、次のとおりです。

| 組 | 収益・費用の勘定:期首の再振替 | 収益・費用の勘定:決算整理 | 収益・費用の勘定:損益 | 経過勘定:前期繰越 | 経過勘定:次期繰越 |
|---|---|---|---|---|---|
| 受取地代・前受地代 | 貸方 | 借方 | 借方 | 貸方 | 借方 |
| 保険料・前払保険料 | 借方 | 貸方 | 貸方 | 借方 | 貸方 |
| 支払利息・未払利息 | 貸方 | 借方 | 貸方 | 貸方 | 借方 |
| 受取利息・未収利息 | 借方 | 貸方 | 借方 | 借方 | 貸方 |

覚えるよりも、仕訳を日付の順に書き出してから記入するほうが確実です。

## まとめ

- 精算表は「試算表 + 修正記入 → 損益計算書欄・貸借対照表欄」。同じ側は足し、反対側は引く
- 当期純利益は、精算表の損益計算書欄の**借方**と、貸借対照表欄の**貸方**に書く
- 損益計算書:売上 → **売上高**、仕入 → **売上原価**。法人税、住民税及び事業税はそのままの名前
- 貸借対照表:繰越商品 → **商品**、経過勘定は **前払費用・未収収益・未払費用・前受収益**
- 貸倒引当金・減価償却累計額は資産から**差し引いて**表示する
- 繰越利益剰余金は、**当期純利益を加えた金額**で表示する
- 締切り:収益・費用は**損益**へ振り替え、損益は**繰越利益剰余金**へ。資産・負債・純資産は**次期繰越**
- 経過勘定の勘定記入:期首の再振替 → 期中の受け取り(支払い) → 決算の前受(前払など) → 損益への振替。経過勘定の残高は次期繰越

#### 問3-1

| 番号 | 解答 |
|---|---|
| ① | 前払保険料 |
| ② | 7,500 |
| ③ | 10,500 |
| ④ | 損益 |
| ⑤ | 39,000 |
| ⑥ | 49,500 |

- ①②:前期末の前払分は、×4年7月に支払った30,000円のうち、×5年4月〜6月の3か月分です。30,000円 × 3 ÷ 12 = 7,500円。期首の再振替仕訳 (保険料)/(前払保険料) で、保険料勘定の借方に入ります
- ③:×5年7月に支払った42,000円のうち、×6年4月〜6月の3か月分が翌期の分です。42,000円 × 3 ÷ 12 = 10,500円
- ④⑤:保険料は費用なので、残高を損益へ振り替えます。7,500円 + 42,000円 − 10,500円 = 39,000円
- ⑥:7,500円 + 42,000円 = 49,500円(貸方も 10,500円 + 39,000円 = 49,500円)
- ⑦:前払保険料は資産なので、残高を「次期繰越」として締め切ります
- ⑧:7,500円 + 10,500円 = 18,000円

完成した勘定は、次のとおりです。

**保険料**

| ×5/7/1 | 普通預金 | 42,000 | ×6/3/31 | 損益 | 39,000 |
| | | 49,500 | | | 49,500 |

**前払保険料**

| 日付 | 摘要 | 金額 | 日付 | 摘要 | 金額 |
|---|---|---:|---|---|---:|
| ×5/4/1 | 前期繰越 | 7,500 | ×5/4/1 | 保険料 | 7,500 |
| ×6/3/31 | 保険料 | 10,500 | ×6/3/31 | 次期繰越 | 10,500 |
| | | 18,000 | | | 18,000 |

当期の保険料39,000円は、4月〜6月の3か月分(1か月2,500円 × 3 = 7,500円)と、7月〜3月の9か月分(1か月3,500円 × 9 = 31,500円)の合計です。
