### 第2問

#### 問1(各2点)

| 番号 | 解答 |
|---|---|
| ① | 前受家賃 |
| ② | 40,000 |
| ③ | 損益 |
| ④ | 120,000 |
| ⑤ | 次期繰越 |

**解説**:当期の受取家賃勘定に記入される仕訳は、次の4つです。再振替は第9章、勘定の締切り(損益への振替と次期繰越)と勘定記入は[第13章 13-5・13-6](13-worksheet-statements.md#13-6-経過勘定の勘定記入)で学んだ内容です。

| 日付 | 仕訳 | 意味 |
|---|---|---|
| ×2/4/1 | (前受家賃)40,000 / (受取家賃)40,000 | 前期末の前受分(4月〜7月の4か月分)の再振替 |
| ×2/8/1 | (普通預金)120,000 / (受取家賃)120,000 | 1年分の受け取り |
| ×3/3/31 | (受取家賃)40,000 / (前受家賃)40,000 | 翌期分(×3年4月〜7月の4か月分)を前受家賃へ |
| ×3/3/31 | (受取家賃)120,000 / (損益)120,000 | 当期の収益を損益勘定へ振り替える |

- ②前受分:×2年8月1日に受け取った1年分のうち、×3年4月〜7月の4か月分が翌期分です。120,000円 × 4か月 ÷ 12か月 = 40,000円
- ②は前受家賃勘定にも出てくるので、①②が前受家賃への振替(決算整理)、③④が損益への振替(決算振替)です
- ④当期の受取家賃:40,000円 + 120,000円 − 40,000円 = 120,000円(ちょうど12か月分)
- 前受家賃は負債なので、決算で残高を「**次期繰越**」として締め切ります。収益の受取家賃は「**損益**」へ振り替えて締め切ります
- 番号のない合計欄は、受取家賃が160,000円、前受家賃が80,000円です
