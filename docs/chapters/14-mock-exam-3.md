試験時間・配点・時間配分は、[第1回の「この章の使い方」](14-mock-exam.md#この章の使い方)と同じです。**60分**を計って解いてください。

第1問の各取引、第2問、第3問は、それぞれ独立した問題です。同じ会社名でも、資料は大問ごとに完結しています。

この回の出題の形は、次のとおりです。

| 大問 | 第1回 | 第2回 | 第3回 |
|---|---|---|---|
| 第2問 | 補助簿の選択、商品有高帳(移動平均法) | 勘定記入、伝票と仕訳日計表 | **商品有高帳(先入先出法)**、**語句の穴埋め** |

## 解答・解説

### 第1問

各3点(1問ごと。勘定科目と金額がすべて合って正解)。

#### 第1問-1

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|---:|---|---:|
| 売上 | 60,000 | 売掛金 | 60,000 |
| 商品 | 40,000 | 売上原価 | 40,000 |

売上原価対立法では、売価の仕訳と原価の仕訳の**両方**を逆にします。返品された商品は手元に戻るので、商品(資産)が増えます(第2章)。

#### 第1問-2

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|---:|---|---:|
| 仕入 | 400,000 | 前払金 | 80,000 |
| | | 買掛金 | 320,000 |

注文したときに支払った手付金は前払金(資産)なので、仕入れたときに前払金を減らし、残りを買掛金にします(第5章)。

#### 第1問-3

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|---:|---|---:|
| 売掛金 | 120,000 | 売上 | 120,000 |
| 発送費 | 3,000 | 現金 | 3,000 |

当社負担の発送費は、売上から差し引かず、**発送費**(費用)にします(第2章)。

#### 第1問-4

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|---:|---|---:|
| 電子記録債権 | 250,000 | 売掛金 | 250,000 |

売掛金(資産)が電子記録債権(資産)に変わります(第4章)。

#### 第1問-5

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|---:|---|---:|
| 借入金 | 1,200,000 | 普通預金 | 1,218,000 |
| 支払利息 | 18,000 | | |

利息は 1,200,000円 × 2% × 9か月 ÷ 12か月 = 18,000円です(第5章)。

#### 第1問-6

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|---:|---|---:|
| 仮払金 | 60,000 | 現金 | 60,000 |

渡した時点では使い道と金額が確定していないので、仮払金(資産)にします(第5章)。

#### 第1問-7

| 借方科目 | 金額 | 貸方科目 | 金額 |
|---|---:|---|---:|
| 備品減価償却累計額 | 480,000 | 備品 | 800,000 |
| 減価償却費 | 120,000 | | |
| 普通預金 | 170,000 | | |
| 固定資産売却損 | 30,000 | | |

- 当期分の減価償却費:800,000円 ÷ 5年 × 9か月(4月〜12月) ÷ 12か月 = 120,000円
- 売却時の帳簿価額:800,000円 − 480,000円 − 120,000円 = 200,000円
- 売却価額170,000円が帳簿価額より30,000円少ないので、売却損です(第6章)

#### 問2(各2点)

| 記号 | 解答 |
|---|---|
| ア | 貯蔵品 |
| イ | 主要簿 |
| ウ | 減価償却累計額 |
| エ | 貸倒引当金 |
| オ | 損益 |

**解説**

- ア:使い残した切手や収入印紙は、決算で費用(通信費・租税公課)から**貯蔵品**(資産)に振り替えます(第9章・第12章)
- イ:**補助元帳**は、補助簿のうち売掛金元帳や商品有高帳のような帳簿の呼び名です。主要簿ではありません(第10章)
- ウ:定率法では、年々小さくなる帳簿価額に償却率を掛けるので、減価償却費は年々少なくなります。**残存価額**は定額法の計算に使う語です(第6章)
- エ:**貸倒損失**は、実際に貸倒れたときの費用です。将来に備えて設定するのは貸倒引当金です(第12章)
- オ:収益と費用は、まず**損益**勘定に集めて当期純利益を計算し、その差額を繰越利益剰余金へ振り替えます。資本金には振り替えません(第13章)
