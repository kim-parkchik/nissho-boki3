# 無料で学べる 日商簿記3級

日商簿記3級を独学で合格したい人のための、無料の教科書と問題集です。
予備知識ゼロから、1章ずつ読んで解いていけば試験範囲をひととおり学べるように作っています。

## 使い方

1. 各章の解説を読み、例題を自分で解いてみる
2. 章末の練習問題を、**紙に仕訳を書いて**解く(印刷して使える[答案用紙](sheets/index.md)もあります)
3. 解答・解説で答え合わせをし、間違えた問題に印をつけて後日もう一度解く

3級の試験は、決まった型の仕訳をすばやく正確に書けるかどうかで差がつきます。
読むだけで終わらせず、手を動かすことがいちばんの近道です。

## 対象範囲

2027年4月1日以降に実施される試験の出題範囲に合わせています。詳しくは [章立てと方針](syllabus.md) を見てください。

!!! warning "2027年3月31日までに受験する人へ"
    2027年3月31日までの試験(ネット試験を含む)は、古い出題範囲で行われます。この教材だけでは範囲が足りません。
    手形・小切手の論点(受取手形・支払手形など)は収録していません。逆に、定率法、固定資産の除却・廃棄、売上原価対立法は、その試験では出題されません。

## 試験のあらまし

| 項目 | 内容 |
|---|---|
| 試験の種類 | 紙の答案用紙に記入する**統一試験**(年3回)と、パソコンで解答する**ネット試験**(随時) |
| 試験時間 | 60分 |
| 問題の構成 | 第1問(45点):仕訳15問程度 / 第2問(20点):帳簿・勘定記入・伝票など / 第3問(35点):精算表・財務諸表など |
| 合格基準 | 100点満点で70点以上 |
| 計算用具 | 電卓(計算機能だけのもの)またはそろばんを使えます |

第1問の勘定科目は、問題ごとに示される選択肢から選んで答えます。この教材では、勘定科目を覚えるために、科目名をそのまま書いて練習します。
最新の試験の情報は、[日本商工会議所の検定試験サイト](https://www.kentei.ne.jp/)で確かめてください。

## 練習問題の印

| 印 | 意味 |
|---|---|
| 【頻出】 | これまでの本試験でくり返し出ている型の問題 |
| 【新範囲】 | 2027年度から3級の範囲に入った論点の問題。3級の本試験では2027年度から出題されるので、必ず練習してください |
