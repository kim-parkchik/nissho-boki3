# 仕訳の答案用紙(共通)

<div class="sheet-note" markdown>

各章の仕訳の練習問題に使える、共通の答案用紙です。左の欄に問題番号を書いて使ってください。1問につき4行あり、印刷すると1ページに8問分が入ります。
印刷のしかたは [答案用紙の使い方](index.md) を見てください。
