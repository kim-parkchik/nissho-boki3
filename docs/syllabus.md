# 章立てと方針

## 前提

- **2027年度適用の出題区分表**(日本商工会議所、2026年7月31日 確定版公表、2027年4月1日以降の試験に適用)に合わせます。
- 3級は**小規模な株式会社**を前提にします。
- 勘定科目は「商業簿記標準・許容勘定科目表(2～3級)」の標準科目を使います。

## 2027年度改定で変わる主な点(3級)

| 区分 | 内容 |
|---|---|
| 削除 | 紙の手形に関する論点(受取手形・支払手形、手形貸付金・手形借入金など)。小切手の振出し・受取りも出題されなくなります |
| 追加 | 現金預金の区分に「普通預金」が明記された(従来から広く使われていた勘定) |
| 2級から移行 | 売上原価対立法(販売のつど売上原価勘定に振り替える方法) |
| 2級から移行 | 有形固定資産の除却・廃棄 |
| 2級から移行 | 定率法による減価償却(償却率を示すなど簡易な出題に限る。保証率・改定償却率は出題しない) |
| 整理 | 電子記録債権・債務は、売掛金・買掛金と同じ区分にまとめられた |
| 明確化 | クレジット売掛金に「キャッシュレス決済を含む」と追記された |
| 参考(変更なし) | リース取引は従来どおり3級の範囲外(家賃・地代は支払家賃・支払地代などで処理) |

> **出典の確認**(2026年11月22日)
> 上の表は、日本商工会議所の次の資料(確定版、2026年7月31日公表)と照らし合わせて確認しました。
>
> - 「商工会議所簿記検定試験出題区分表(2022年度版からの変更箇所を記載)」
> - 「紙媒体による手形・小切手の廃止および企業会計基準第34号「リースに関する会計基準」等の適用にともなう商工会議所簿記検定試験出題区分表などの改定について【確定版】」
> - 「商業簿記標準・許容勘定科目表(2～3級)」(2026年7月31日 最終改定、2027年4月1日施行)
>
> いずれも [日本商工会議所の検定試験サイト](https://www.kentei.ne.jp/51147)([出題区分表のページ](https://www.kentei.ne.jp/bookkeeping/exam-list))から入手できます。
> 教材の仕訳で使う勘定科目は、すべて勘定科目表の3級A欄(標準)の科目、またはその「各勘定」(前払保険料・未払利息など)です。

## 章立て

| 章 | タイトル | 主な内容 |
|---|---|---|
| 1 | 簿記の基本と仕訳 | 簿記の目的、5つのグループ、貸借対照表と損益計算書、取引の8要素、仕訳と転記 |
| 2 | 商品売買 | 三分法、売上原価対立法、返品、仕入諸掛り・売上諸掛り |
| 3 | 現金・預金 | 現金、現金過不足、普通預金、当座預金、当座借越、定期預金、小口現金 |
| 4 | 売掛金・買掛金と電子記録債権・債務 | 売掛金・買掛金、クレジット売掛金、電子記録債権・債務 |
| 5 | その他の債権・債務 | 貸付金・借入金(月割・日割の利息)、未収入金・未払金、前払金・前受金、仮払金・仮受金、立替金・預り金、受取商品券、差入保証金 |
| 6 | 有形固定資産 | 取得(付随費用)、改良と修繕、減価償却(定額法・定率法)、売却、除却・廃棄 |
| 7 | 株式会社の純資産 | 株式の発行、資本金、繰越利益剰余金、剰余金の配当 |
| 8 | 税金 | 租税公課、法人税等、消費税(税抜方式) |
| 9 | 収益・費用と訂正仕訳 | 費用・収益の前払い・前受け・未払い・未収、再振替仕訳、貯蔵品、訂正仕訳、その他の収益・費用の勘定科目 |
| 10 | 帳簿と伝票 | 主要簿と補助簿(記入例)、商品有高帳、証ひょう、3伝票制、仕訳日計表 |
| 11 | 試算表 | 合計試算表、残高試算表、合計残高試算表 |
| 12 | 決算整理 | 売上原価の算定、貸倒れと貸倒引当金、減価償却、経過勘定、現金過不足の整理、月次決算、翌期首の再振替など |
| 13 | 精算表と財務諸表 | 精算表、決算整理後残高試算表、損益計算書、貸借対照表、帳簿の締切り、経過勘定の勘定記入 |
| 14 | 総合問題(模擬試験) | 本試験形式(第1問〜第3問)の模擬問題5回分。第2問・第3問は回ごとに形式を変える(補助簿・商品有高帳・勘定記入・伝票・語句・小口現金出納帳・売掛金元帳・固定資産台帳・仕入帳/財務諸表・精算表・決算整理後残高試算表)。第4回・第5回は第1回〜第3回で出題しなかった論点を中心にする |
