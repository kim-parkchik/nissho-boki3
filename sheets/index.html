    答案用紙の使い方¶

    日商簿記3級の試験には、紙の答案用紙に記入する統一試験と、パソコンの画面で入力するネット試験があります。 どちらの試験でも、精算表・財務諸表・帳簿などの問題では、勘定科目や行の並びがあらかじめ用意された欄に金額などを記入します。 このページの答案用紙を印刷して使うと、本試験に近い形で練習できます。 ネット試験でも、配られる計算用紙に下書きをしてから画面に入力するので、紙に書いて解く練習が役に立ちます。

    印刷のしかた¶

    1. 使いたい答案用紙のページを開きます
    2. ブラウザの「印刷」を選びます(Windowsは Ctrl + P、Macは ⌘ + P)
    3. 用紙サイズを A4、向きを縦、倍率を 100% にします
    4. 「ヘッダーとフッター」の設定があれば、オフにします

    印刷すると、サイトのメニューや案内文は消え、答案用紙の部分だけが印刷されます。 模擬試験の答案用紙は、大問ごとに新しいページから始まります。 印刷の見た目は Google Chrome で確認しています(Microsoft Edge も同じしくみのブラウザです)。Safari と Firefox では確認していないので、うまく印刷できないときは Chrome か Edge を使ってください。 サイトを暗い配色(ダークモード)で見ているときは、画面右上の切り替えで明るい配色にしてから印刷してください。

    ヒント:印刷せずに、タブレットやノートに書き写して使ってもかまいません。

    答案用紙を使うときの注意¶

    • 勘定科目の欄の「(　　　)」は、自分で勘定科目(またはその一部)を書き入れる欄です。本試験でも、このような空欄が出ることがあります
    • 貸借対照表の「売掛金 (　　　　)」のかっこには売掛金などの金額を、「△(　　　　)」のかっこには差し引く貸倒引当金や減価償却累計額の金額を書きます。差し引いた後の金額は、その下の行の金額欄に書きます
    • 模擬試験と第13章の仕訳の欄は、1問につき4行あります。すべての行を使うとは限りません
    • 試算表・精算表・財務諸表の「合計」の行は、借方と貸方(左右)が一致するかを最後に確かめるために使います
